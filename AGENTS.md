# AGENTS.md — карта проекта PsychAI для AI-агентов

Краткая карта, а не инструкция. Подробности — в docs/ (ссылки ниже).
Новый агент: сначала прочитай этот файл, затем START_HERE.md.

## Назначение
PsychAI — ассистент для психологов (помогает специалисту, НЕ заменяет
его). Локальное приложение под Windows: захват аудио разговора →
потоковая транскрипция → (в будущем) анализ в помощь специалисту.

## Стек (фиксирован, версии не менять)
Python 3.12 · PySide6 (UI) · faster-whisper + ctranslate2 (STT) ·
PyAudioWPatch (WASAPI-захват).

## Структура проекта
- capture/        — захват аудио (WASAPI loopback), вход в конвейер
- transcription/  — STT (StreamingTranscriber), только распознавание
- orchestrator/   — координация жизненного цикла компонентов
- llm/            — анализ текста (пока пусто, будущее)
- ui/             — интерфейс (PySide6)
- session/        — сессия разговора
- tools/          — служебные скрипты и эксперименты (не код продукта)
- experiments/    — артефакты прогонов (gitignored)
- docs/           — система знаний проекта
- run_stream.py   — консольный MVP потоковой транскрипции

## Основные архитектурные правила
- Базовая ось: Orchestrator — Session — Audio — Memory — LLM.
- Модули общаются ТОЛЬКО через Orchestrator; напрямую не связываются.
- Orchestrator НЕ обрабатывает сырой PCM (только создаёт/соединяет/
  управляет жизненным циклом); PCM течёт capture → transcriber.
- Одна ответственность на каталог (см. Структуру).
- Тюнинги (окна, пороги) — параметры конфигов, не хардкод.
- Ctrl+C = чистый останов всех потоков и ресурсов (в finally).

## Как запускать проверки
- Среда: python tools/verify_environment.py  (ожидается exit 0)
- MVP:   python run_stream.py  (опции --window --language --model)
- Тесты: pytest -q  (если тесты присутствуют)
