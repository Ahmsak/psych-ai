# docs/adr — Architecture Decision Records

Каждое ADR — отдельный короткий файл: причины ОДНОГО архитектурного
решения, а не история проекта. Один файл = одно решение.

Файл: ADR-NNN-<краткое-имя>.md. Нумерация сквозная и продолжает лог
docs/ARCHITECTURAL_DECISIONS.md (ADR-001…005 — там; новые ADR, начиная
с ADR-006, ведутся здесь отдельными файлами).

Формат — см. ADR-000-template.md:
Title · Status · Context · Decision · Consequences. Держать коротким.
