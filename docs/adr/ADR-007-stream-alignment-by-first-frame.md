# ADR-007: Выравнивание потоков по времени первого аудиокадра

## Status
Accepted

## Context
Sprint 6 (Session Alignment) строит единую временную шкалу разговора из
двух независимых потоков (mic + loopback). Нужен воспроизводимый способ
вычислить смещение (offset) между потоками, используя ТОЛЬКО объективные
данные из metadata.json, без эвристик и LLM.

Доступные объективные метки (Sprint 5): на каждый поток —
`record_start` (момент старта записи, до открытия устройства) и
`first_frame_at` (момент появления первого реального аудиокадра).
Обе — wall-clock (`time.time()`) одного процесса: годятся для грубого
выравнивания (порядок десятков мс), но НЕ сэмпл-точны.

Рассмотренные варианты offset:
1. по `first_frame_at` — разница момента первого реального кадра;
2. по `record_start` — разница момента старта записи;
3. кросс-корреляция сигналов — точнее, но это эвристика обработки
   сигнала, менее воспроизводима и сложнее (против MVP-first).

## Decision
Session start = min(record_start обоих потоков).
Offset потока = first_frame_at(поток) − Session start.
Межпотоковый offset = loopback.first_frame_at − mic.first_frame_at.
Единая шкала строится от Session start; каждый поток размещается по
своему first_frame offset. Интервал записи потока =
[record_start, record_start + duration_sec].

Выбран вариант 1 (`first_frame_at`): он отражает реальное начало звука
(исключает задержку открытия устройства, в отличие от `record_start`) и
опирается только на уже зафиксированные объективные метки. Вариант 3
отклонён как эвристика и усложнение.

## Consequences
- (+) Простой, воспроизводимый offset из готовых данных metadata.json.
- (+) Никаких эвристик/LLM/обработки сигнала — соответствует целям
  Sprint 6 и ADR-006 (дорожки независимы).
- (+) `record_start` сохраняется как запасная, более грубая метка.
- (−) Точность ограничена wall-clock (~десятки мс), не сэмпл-точна;
  для будущего точного выравнивания может потребоваться отдельное
  решение (напр. общий монотонный источник времени) — вне Sprint 6.
- Аудио НЕ микшируется и НЕ синхронизируется физически; строится только
  временная модель (Timeline).
