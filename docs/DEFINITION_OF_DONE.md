# DEFINITION_OF_DONE — критерии завершения Sprint

Sprint считается завершённым ТОЛЬКО после выполнения всех пунктов.
Обновляется при изменении процесса (через владельца проекта).

## Чек-лист

1. [ ] Код работает: целевой сценарий спринта реально запущен и дал
       ожидаемый результат (для STT — run_stream.py; e2e где возможно).
2. [ ] Выполнены необходимые проверки:
       - python tools/verify_environment.py → RESULT: OK (warnings
         допустимы, только если зафиксированы в PROJECT_STATE.md);
       - ручные проверки затронутых модулей (tests/).
3. [ ] Корректное завершение: нет зависших потоков/процессов после
       остановки (Ctrl+C-путь проверен, если менялся конвейер).
4. [ ] Ограничения спринта соблюдены (ничего из списка Deferred
       не реализовано без явного разрешения владельца).
5. [ ] Документация обновлена по docs/DOCUMENTATION_LIFECYCLE.md:
       - docs/PROJECT_STATE.md — Completed/Current/Next/Known Issues/
         Technical Debt/Deferred/Last Update;
       - docs/SESSION.md — запись о сессии;
       - ADR добавлен в docs/ARCHITECTURAL_DECISIONS.md, если было
         принято архитектурное решение;
       - README модулей / ENVIRONMENT / DEPENDENCIES — если менялись
         интерфейсы, среда или библиотеки;
       - START_HERE.md — если сменился Sprint или способ запуска.
6. [ ] git status чистый: всё нужное закоммичено, лишнее не попало.
7. [ ] git commit выполнен (осмысленные сообщения, стиль из
       docs/DEVELOPMENT_WORKFLOW.md).
8. [ ] git push выполнен — изменения в GitHub
       (https://github.com/Ahmsak/psych-ai). Незапушенный Sprint
       НЕ считается завершённым.
9. [ ] Владельцу проекта предоставлен итоговый отчёт: изменённые файлы,
       что реализовано, как запускать, как протестировать.
