# SPEC-001: Unified Audio Timeline (подготовка к объединению потоков)

## Purpose
Подготовить надёжную временную основу для будущего объединения двух
независимых аудиопотоков (Microphone + WASAPI Loopback) в единый диалог.
Только основа: единый формат, временные метки, метаданные и измеримые
проверки. Само объединение/синхронизация/диаризация/анализ — вне спринта.

## Requirements
- Оба потока приводятся к единому формату: 48000 Гц, mono, PCM int16.
- Для каждого потока фиксируется временная информация:
  - время старта записи (record_start, ISO-8601);
  - время появления первого аудиокадра (first_frame_at);
  - длительность записи (duration_sec);
  - параметры устройства (имя, native sample rate/channels).
- Создаётся metadata.json на прогон: session_id, created_at, единый
  формат, блок на каждый поток (mic, loopback) с параметрами и временем.
- Обе дорожки записываются и транскрибируются раздельно (как в Sprint 4).
- Артефакты прогона: mic.wav, loopback.wav, *_transcription.txt,
  metadata.json (+ существующие log.txt/manifest.json).

## Constraints
- НЕ объединять WAV, НЕ микшировать, НЕ синхронизировать дорожки.
- НЕ диаризация, НЕ анализ разговора, НЕ LLM.
- НЕ менять архитектуру: ось GUI→Orchestrator→Session→Audio→Memory→LLM
  неизменна; экспериментальный код только в tools/.
- Фикс. стек и версии (Python 3.12, faster-whisper, PyAudioWPatch).
- Ресемплинг в единый формат — переиспользовать существующую логику
  transcription/ (не дублировать алгоритм).

## Acceptance Criteria (sensor-first, PASS/FAIL)
- FAIL, если устройство не открылось (записана ошибка, не краш).
- FAIL, если фактический sample rate потока != заявленному в metadata.
- FAIL, если запись отсутствует (WAV нет или 0 кадров при audio_captured).
- FAIL, если metadata.json не создан или не парсится / нет ключей.
- FAIL, если WAV повреждён (не открывается wave-модулем).
- FAIL, если транскрипция не создана при наличии звука (RMS выше порога).
- Проверки вынесены в детектор tools/check_experiment.py (exit!=0 = FAIL)
  и покрыты pytest на синтетических артефактах.

## Definition of Done
См. docs/DEFINITION_OF_DONE.md (единый чек-лист). Дополнительно для

Sensor-first проверки работают.
