## Проблема №2 — на MIC слышны обе стороны (инженерное расследование)

### Измерения (по этому эксперименту)
- mic rms=74.7, loopback rms=1974.2 (loopback ~26× громче).
- Кросс-корреляция энергетических огибающих mic vs loopback:
  - без учёта офсета: corr≈0.12 (низкая);
  - при сдвиге −12.9 с (совпадает с offset loopback 13.0 с из metadata):
    **corr=0.952** (очень высокая).
- Уровень mic в моменты, выровненные по громкому клиенту (loopback):
  - когда клиент ГРОМКО: mic mean rms = **130.5**;
  - когда клиент тихо: mic mean rms = **14.2**.

### Вывод: смешивание/утечка ЕСТЬ (в аудио, не в коде)
Корреляция 0.95 после выравнивания по офсету + рост уровня mic именно
тогда, когда громко звучит клиент, доказывают: **голос клиента физически
присутствует в MIC WAV**. Это не программное смешивание — PsychAI пишет
два независимых потока и НЕ объединяет их (проверено: source-раскладка
mic=0/loopback=19, кода микширования нет).

### Что это НЕ (исключено)
- НЕ ошибка PsychAI: два потока пишутся раздельно, микширования в коде нет;
  mic.wav содержит ровно то, что отдало устройство захвата микрофона.
- НЕ WASAPI loopback «протёк» в микрофон: loopback пишется отдельным
  устройством; сам факт — что клиент слышен во ВХОДЕ микрофона.

### Наиболее вероятная причина (по приоритету)
1. **Акустическая утечка**: звук клиента играет через динамики/открытую
   гарнитуру и попадает обратно в микрофон Realtek. Согласуется с тем, что
   mic-копия клиента тихая (rms 130 против 1974 в loopback) и запаздывает.
2. **Realtek «Stereo Mix»/усиление микрофона**: драйвер Realtek может
   подмешивать выходной сигнал во вход (функция мониторинга/«прослушивание
   устройства»/Stereo Mix), либо AGC/boost поднимает фоновый звук.
3. WhatsApp Desktop эхо/мониторинг — маловероятно (звонок не должен
   заворачивать выход во вход), но не исключено полностью.

### Как различить причины (диагностика, НЕ исправление)
- Проверить в Windows: mmsys.cpl → Запись → Микрофон → Прослушать
  («Listen to this device») ВЫКЛ; вкладка «Уровни» — boost 0 dB;
  отключить «Stereo Mix» если включён.
- Тест с наушниками (закрытыми): если клиент пропадает из mic → это
  акустическая утечка через динамики.
- Тест «тишина в звонке + речь психолога»: записать mic — если
  psychologist громкий и чистый, микрофонный тракт исправен.

### Влияние
- Пока НЕ выполняется объединение/диаризация — утечка не портит
  Conversation (клиент берётся из loopback, mic всё равно почти пуст).
- НО для будущего (речь психолога + разделение сторон) утечка критична:
  слабый голос психолога + подмешанный клиент делают mic ненадёжным.

### Причина установлена (для №2)
Смешивание происходит на уровне АУДИО-ЗАХВАТА (акустическая/драйверная
утечка клиента во вход микрофона), НЕ в коде PsychAI. Точную причину
(акустика vs Realtek Stereo Mix/monitoring) подтвердит диагностика выше.
