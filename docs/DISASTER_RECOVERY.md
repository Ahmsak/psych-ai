# DISASTER_RECOVERY — восстановление проекта PsychAI

Сценарий: локальная машина потеряна (поломка, кража, переустановка ОС).
Цель: полное восстановление рабочего состояния проекта на новой машине.
Обновляется при изменении процедуры восстановления или состава среды.

## Что где хранится

| Артефакт | Где | Восстановимо |
|---|---|---|
| Код, документация, знания проекта | GitHub: https://github.com/Ahmsak/psych-ai | git clone |
| Зависимости Python | requirements.txt (в репозитории) | pip install |
| Модель Whisper small | HuggingFace (кэш ~/.cache/huggingface) | скачается при первом запуске |
| test.wav (тестовый артефакт) | только локально (*.wav в .gitignore) | НЕ критично; любой WAV с речью подходит |
| Правила/среда | docs/ENVIRONMENT.md, docs/DEPENDENCIES.md | в репозитории |

Всё критичное живёт в GitHub. Поэтому правило проекта:
каждый завершённый Sprint ОБЯЗАН быть запушен (DEFINITION_OF_DONE п.8).

## Процедура восстановления (новая машина, Windows 10/11)

1. Установить Python 3.12 (x64) с python.org, с галочкой "Add to PATH".
2. Установить Git for Windows.
3. Клонировать проект:
       git clone https://github.com/Ahmsak/psych-ai.git
       cd psych-ai
4. Установить зависимости (версии зафиксированы):
       pip install -r requirements.txt
   Если ctranslate2/onnxruntime падают при импорте — установить
   Microsoft Visual C++ Redistributable (x64, latest).
5. Проверить среду:
       python tools/verify_environment.py
   Ожидается RESULT: OK (допустимые warnings описаны в docs/ENVIRONMENT.md).
6. Смок-тест конвейера:
       python run_stream.py
   Включить любой звук с речью → в консоли появляются строки ">> ...".
   Ctrl+C → "stopped cleanly". При первом запуске модель Whisper small
   скачается автоматически (нужен интернет, ~500 МБ).
7. Восстановить контекст разработки: START_HERE.md → docs/*
   (порядок чтения указан в START_HERE.md).

Ориентировочное время: 20–40 минут (большая часть — скачивания).

## Проверка готовности к катастрофе (периодически)

- git status чистый и origin/main не отстаёт:
      git status && git log --oneline -1 origin/main
- Незапушенных завершённых спринтов нет (правило DoD п.8).
- verify_environment.py проходит.

## Чего процедура НЕ покрывает

- Секреты/ключи API — в проекте их пока нет; при появлении LLM-ключей
  завести .env (в .gitignore) и описать здесь способ их восстановления.
- Данные сессий психолога — продукт пока их не хранит; при появлении
  Storage потребуется отдельная стратегия бэкапа (новый ADR).
- Аудиооборудование: WASAPI loopback требует любого устройства вывода
  звука; на серверных/виртуальных машинах без аудио capture не заработает.
