# GLOSSARY — словарь терминов PsychAI

Определения короткие и однозначные. Обновляется при появлении новых
терминов в архитектуре или предметной области.

## Предметная область

- **Session (Сессия)** — одна встреча психолога с клиентом, сопровождаемая системой.
- **Episode (Эпизод)** — значимый смысловой фрагмент сессии или серии сессий.
- **Fact (Факт)** — атомарное проверяемое утверждение без интерпретации.
- **Evidence (Доказательство)** — данные, на которых основан вывод.
- **Observation (Наблюдение)** — зафиксированное событие без интерпретации.
- **Hypothesis (Гипотеза)** — предположительная интерпретация фактов с явной неопределённостью.
- **Narrative (Нарратив)** — связное изложение истории клиента, собранное из эпизодов.
- **Context (Контекст)** — информация, доступная компоненту в момент работы.

## Архитектура

- **Orchestrator (Оркестратор)** — единственный координатор: создаёт, соединяет и останавливает компоненты; данные не транспортирует.
- **Agent (Агент)** — специализированный ИИ-компонент анализа; общается только через Оркестратор.
- **Validator (Валидатор)** — проверяет рекомендации на соответствие Constitution до показа психологу.
- **Memory (Память)** — хранилище фактов продукта; выводы не хранит.
- **Constitution (Конституция)** — централизованный свод этических правил, независимый от LLM.

## Аудио / STT

- **Capture (Захват)** — получение сырого системного звука Windows (WASAPI loopback).
- **Loopback** — механизм WASAPI, отдающий копию звука устройства вывода.
- **PCM** — сырые несжатые аудиосэмплы (int16).
- **Chunk (Чанк)** — порция PCM, передаваемая из capture в transcription.
- **Streaming (Потоковая обработка)** — обработка звука по мере поступления.
- **Transcription (Транскрипция)** — преобразование речи в текст (faster-whisper).
- **Window (Окно)** — отрезок аудио длиной window_duration_sec, транскрибируемый за один вызов модели.
- **RMS-гейт** — пропуск почти беззвучных окон по порогу громкости.

## Процесс

- **Sprint** — ограниченный этап работы с явными целями и правилами.
- **ADR** — запись архитектурного решения (ARCHITECTURAL_DECISIONS.md).
- **MVP** — минимальный работающий продукт.
