# OWNER_DECISIONS — решения владельца проекта

Журнал обязательных решений владельца, не являющихся архитектурными
(те — в ARCHITECTURAL_DECISIONS.md). Записи добавляются, не
редактируются; отмена решения = новая запись со ссылкой на старую.

Формат: номер, дата, решение, контекст/границы.

## OD-001 — 2026-07 — Продукт ассистирует психологу, не заменяет его
Границы: любые будущие функции проверяются на соответствие этому
принципу; ответственность всегда за человеком.

PySide6 (GUI), PyAudioWPatch (захват), faster-whisper + ctranslate2 (STT).
Версии из requirements.txt не менять без необходимости; среду не
переустанавливать; проблемы среды сначала сообщать, не чинить молча.

## OD-003 — 2026-07 (Sprint 3) — Приоритеты разработки
1) рабочий MVP; 2) переиспользование существующего кода;
3) минимум изменений; 4) архитектурная чистота; 5) только потом
оптимизация. Рабочий код не переписывать без объективной причины.

## OD-004 — 2026-07 (Sprint 3) — Отложено на отдельные спринты
Не реализовывать без явного разрешения: VAD, Speaker Diarization,
Endpoint Detection, Partial Results, Streaming Decoder, Overlap,
Buffer Optimization, LLM-анализ.
